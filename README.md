 Pop Mart Trendy Toy Data Analysis Dashboard
> Personal independent data‑analysis project | Web‑based interactive visualization built with Python Flask & ECharts

 Project Overview
This project implements a complete web‑based data analysis dashboard for Pop Mart trendy toy business scenarios.
Simulated CSV datasets are adopted to explore IP performance, multi‑platform sales distribution, public sentiment feedback, search heat trend and user group characteristics.

The front‑end adopts multi‑tab interactive design. It integrates core business metrics statistics and multi‑dimensional chart visualization, helping analysts observe market performance of trendy‑toy products.
No external database is required; all data is loaded from local CSV files.

 Tech Stack
Backend
- Python 3.x
- Flask: build RESTful API service for data access
- Pandas: data parsing, cleaning and statistical calculation

 Frontend
- HTML / Vanilla JavaScript
- Apache ECharts: implement bar chart, pie chart, line chart and other interactive visual components

 Dataset
- Local CSV simulated business data
- No third‑party database dependency
